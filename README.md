# Бот слежения за ценами Aviasales → Telegram-канал

Сейчас настроен на маршрут **Новосибирск → Нячанг**, в одну сторону, вылет
в любой день **с 20.11.2026 по 20.12.2026**. Бот каждые ~10 минут находит самый
дешёвый билет в этом диапазоне и пишет в канал, если цена ушла от последней
опубликованной на **2000 ₽ и больше**: 📉 упала или 📈 выросла.

Работает круглосуточно и бесплатно на GitHub Actions, компьютер включённым держать не нужно.

---

## Шаг 1. Бот в Telegram
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя.
2. Сохрани токен вида `123456789:AA...`.
3. Канал → Управление каналом → Администраторы → добавь своего бота
   с правом **«Публикация сообщений»**.
4. Адрес канала: `@username` для публичного канала. Для приватного нужен
   числовой id вида `-100...`: перешли любой пост из канала боту
   [@userinfobot](https://t.me/userinfobot), он покажет id.

## Шаг 2. Токен Aviasales (Travelpayouts)
1. Зарегистрируйся на [travelpayouts.com](https://www.travelpayouts.com/) (бесплатно).
2. Подключи программу **Aviasales**.
3. Найди **API token** в профиле (раздел «Инструменты» → API) и сохрани его.

## Шаг 3. Залей бота на GitHub
1. Зарегистрируйся на [github.com](https://github.com/).
2. Справа вверху **+** → **New repository** → любое имя, например `avia-bot`,
   тип **Public** → **Create repository**.
   *(В публичном репозитории GitHub Actions бесплатны без ограничений.
   Токены туда не попадут: они хранятся в закрытых Secrets, см. шаг 4.)*
3. На странице репозитория нажми **uploading an existing file** и перетащи туда
   **всё содержимое папки** с ботом, включая папку `.github`:
   `bot.py`, `config.json`, `config.example.json`, `README.md`, `.github`.
   → **Commit changes**.
   > Если папка `.github` не видна в проводнике, включи «Вид → Скрытые элементы».
   > Если она всё же не загрузилась: **Add file → Create new file**, имя
   > `.github/workflows/price-watch.yml`, вставь содержимое этого файла.

## Шаг 4. Добавь токены в Secrets
Репозиторий → **Settings** → **Secrets and variables** → **Actions** →
**New repository secret**. Создай три секрета:

| Name | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHANNEL_ID` | `@username` канала или `-100...` |
| `TRAVELPAYOUTS_TOKEN` | токен Travelpayouts |

## Шаг 5. Включи и проверь
1. Вкладка **Actions**. Если GitHub спросит, нажми
   **I understand my workflows, go ahead and enable them**.
2. Слева **Price watch** → **Run workflow** → поставь галочку
   «Только отправить тестовое сообщение» → **Run workflow**.
   В канале должно появиться «✅ Бот подключён…».
3. Ещё раз **Run workflow**, уже без галочки. В канал придёт текущая цена
   («👀 Начинаю следить…»).

Дальше бот сам запускается каждые 10 минут. Последняя цена хранится в файле
`state.json` в репозитории, бот обновляет его сам.

---

## Как поменять маршрут или даты
Открой `config.json` в репозитории → ✏️ (Edit) → поменяй → **Commit changes**.

| Поле | Что это |
|---|---|
| `origin`, `destination` | IATA-код города: `OVB` Новосибирск, `NHA` Нячанг, `MOW` Москва… |
| `depart_from`, `depart_to` | диапазон дат вылета `ГГГГ-ММ-ДД`: ищется самый дешёвый день в нём |
| `depart_date` | вместо диапазона: одна дата `ГГГГ-ММ-ДД` или целый месяц `ГГГГ-ММ` |
| `return_date` | дата обратно, если нужен билет туда-обратно |
| `direct` | `true`: только прямые рейсы |
| `min_change` | порог в рублях: меньшие изменения не публикуются |

Маршрутов может быть несколько, добавляй их в список `routes`.
Если поменял даты, удали `state.json` из репозитория, чтобы бот начал отсчёт заново.

## Как остановить
**Actions** → **Price watch** → **⋯** → **Disable workflow**.

## Запуск на своём компьютере (необязательно)
Впиши токены прямо в `config.json` (только не заливай такой файл на GitHub!) и запусти:
```bash
python bot.py --dry-run
```
Эта команда только покажет цены и будущие сообщения, ничего не отправляя. Без `--dry-run`
бот будет работать постоянно, пока открыто окно.

## Важно знать
- Travelpayouts отдаёт **кэшированные** цены: то, что люди находили на Aviasales
  за последние ~2 суток. Цена в канале может немного отличаться от той,
  что сайт покажет при поиске прямо сейчас.
- GitHub запускает задачи по расписанию с задержкой, иногда до 15–30 минут
  в часы пик. Совсем без задержек будет только на своём VPS.
